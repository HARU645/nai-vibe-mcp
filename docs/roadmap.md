# 로드맵
- 상태: v0.3까지 확정, 그 뒤는 제안 (2026-10-12)
- 이 문서는 "무엇을, 왜, 언제쯤". 구현 방법과 완료 기준은 기능마다 `docs/specs/`의 스펙에 씀
- Claude Code는 이 문서만 보고 구현하지 않음. 스펙이 `준비됨`인 것만 구현

## 방향
1. **말로 끝까지**: 태그·가중치 문법을 몰라도 한국어 대화만으로 원하는 그림까지 감
2. **돈이 새지 않는 도구**: 비용 가드가 제일 먼저. 비싼 기능일수록 미리 보여 주고 확인받음
3. **내 취향이 쌓이는 도구**: 화풍·캐릭터·좋았던 결과가 쌓여서 다음 생성이 점점 쉬워짐
4. **작게, 단단하게**: 기능 개수로 경쟁하지 않음. 한 버전에 한 주제
5. NovelAI 약관과 비공식 원칙을 지킴 (동시 요청 금지, 웹인 척하는 헤더 금지, 로고 사용 금지)
