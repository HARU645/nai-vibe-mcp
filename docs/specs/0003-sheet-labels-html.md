# 0003 시트에 칸 이름 붙이기 + sheet.html
- 상태: 준비됨
- 목표 버전: v0.3.0
- 작성: 2026-10-12
- 로드맵: A1
- 먼저 할 것: 0002 (시트 묶음 배치가 바뀌므로 그 위에 얹음)

## 문제
- 지금 시트 이미지(`sheet.jpg`)엔 번호만 있어서, 번호 ↔ 태그 대응을 결과 글이나 `sheet.txt`를 따로 봐야 앎. 시트 이미지만 저장하거나 남에게 보여 주면 무슨 작가인지 알 수 없음
- 2026-10-12에 작가 카탈로그를 만들 때 이름·메모 라벨을 손으로 붙여야 했음
- 사용자 요청 (2026-10-12): **긴 글을 "…"로 자르지 말고 줄을 바꿔 끝까지 보여 줄 것**

## 목표
- 시트 이미지만 봐도 칸마다 무슨 태그인지 보임 (자르지 않고 줄바꿈)
- 같은 폴더의 `sheet.html`을 브라우저로 열면 칸마다 전체 태그·이름·모델·시드·원본 그림을 한눈에 볼 수 있음
- 도구가 보여 주는 다른 목록에서도 "…" 생략을 없앰

## 범위 밖
- 시트 이미지에 한글 그리기: 한글 글꼴을 넣으면 `.mcpb`가 수 MB 커짐 → 이미지에는 영문 태그만, 한국어 이름(라벨)은 `sheet.html`에
- 칸마다 사용자 메모 붙이기: 작가 메모장(로드맵 A5, v0.4)에서

## 동작

### 시트 이미지 라벨
- 칸 묶음 아래에 그 칸의 **태그(prompt)** 를 적음. 기준 칸은 `BASE (no style tag)`
- 줄바꿈: 칸 폭 안에서 줄을 바꾸고, 가능하면 `, ` 경계(태그 단위)에서 바꿈. 태그 하나가 칸 폭보다 길면 글자 단위로 바꿈. **생략("…") 금지**
- 한 줄(행)의 라벨 영역 높이 = 그 행에서 가장 줄이 많은 칸에 맞춤
- 글자: ASCII만 그림. ASCII가 아닌 글자는 `?`로 바꾸지 말고 그 부분만 빼고, 칸 아래에 영문 표시 `see sheet.html`
- 글꼴: 0002에서 만든 ASCII 비트맵 글꼴을 씀 (크기 2배로 그려서 읽기 쉽게). **JS 코드 안에 내장한 비트맵만** — 네이티브 모듈 금지, 별도 글꼴 파일 금지 (`scripts/pack-mcpb.mjs`는 `index.mjs`·아이콘·README·LICENSE만 넣으므로 따로 둔 파일은 배포에서 빠짐)
- 라벨 배치는 "칸 폭 → 줄 목록"을 돌려주는 함수로 분리해서 단위 테스트할 수 있게 (픽셀로 글자를 확인하기 어려우므로)
- 0002의 시트 크기 상한(긴 변 최대 2000px)은 라벨 영역까지 포함해서 지키려고 하되, 조건이 부딪치면 이 순서로 양보:
  1. **생략 금지**는 끝까지 지킴
  2. 넘치면 그림 폭을 줄임 (최소 128px)
  3. 그래도 넘치면 라벨 글자를 2배 → 1배 크기로
  4. 그래도 넘치면(태그가 수백 자이거나 그림 비율이 극단적인 경우) 상한을 넘는 걸 허용하고 결과에 한 줄: "시트가 커서 앱에서 줄여 보일 수 있습니다. 칸마다 전체 내용은 sheet.html에서 볼 수 있습니다."
- 그림 폭 256px이면 한 줄 약 20자, 128px이면 약 10자. 섞기 3명짜리 태그(80자 안팎)가 여러 줄이 되는 건 정상

### sheet.html
- `sheet.jpg`, `sheet.txt` 옆에 `sheet.html`을 같이 저장
- 한 파일로 완결: 외부 글꼴·스크립트·CSS 불러오기 없음
- 그림 경로는 시트 기록의 **실제 파일 경로**에서 만듦 (이름이 겹쳐 `_2`가 붙었을 수도 있으므로 짐작해서 만들지 않음)
  - `sheet.html`과 같은 폴더면 파일 이름만 (`<img src="03_v5-full_20261012.png">`)
  - 다른 폴더면(저장 폴더에 못 써서 임시 폴더로 간 경우 등) `file:///` URL로. Windows 역슬래시는 `/`로 바꾸고 경로는 URL 인코딩
- 내용
  - 맨 위: 시트 id, 모델(들), 크기, 스텝, 시드(들), 공통 프롬프트(전체), 프리셋 이름
  - 칸마다: 번호, 라벨(한국어 가능), 태그 전체(고정폭, 줄바꿈), 그 칸의 그림들(모델·시드 표시), 생성 안 된 그림은 "생성 안 됨" 표시, 기준 칸 표시
  - 그림은 화면 폭에 맞춰 줄어들고, 누르면 원본 PNG가 열림 (`<a href>`)
- 태그 복사 버튼은 선택 사항 (넣는다면 인라인 스크립트 몇 줄, 외부 요청 없음)
- 라벨·태그·프롬프트는 모두 HTML 이스케이프 (사용자·AI가 쓴 글이 그대로 들어가므로)
- 다크 모드에서도 읽히게 (`prefers-color-scheme`)
- 저장 실패해도 시트 결과는 정상으로 끝내고 알림 한 줄 (지금 `sheet.txt`와 같은 방식)

### 도구 결과
- 결과 글에 `sheet.html` 경로 한 줄: "브라우저로 열면 칸마다 전체 태그를 볼 수 있습니다: <경로>"
- `structuredContent.sheet_html` 추가
- 시트 기록(`sheets.jsonl`)에 `htmlFile` 추가 (저장에 성공했을 때만)

### 같이 처리할 작은 것 — "…" 생략 없애기
- `nai_preset list`가 프롬프트를 80자에서 "…"로 자름 (`src/tools.ts`) → 전체를 보여 줌
- 그 밖에 사용자에게 보이는 결과 글에서 "…"로 자르는 곳이 있으면 같이 정리
- 예외: NovelAI 서버 오류 원문(`src/api/client.ts`에서 500자·200자로 자르는 곳)은 길이 제한을 그대로 두고, 표시 없이 잘리던 것을 끝에 "(이하 생략)"을 붙이게만 바꿈. 원문 전체를 파일로 남기지는 않음 (토큰 등이 섞일 수 있어서)

## 완료 기준
1. 태그가 짧은 칸·긴 칸(80자 이상)·기준 칸이 섞인 시트에서 라벨이 칸 폭을 넘지 않고, "…" 없이 전부 그려짐 (라벨 줄바꿈 함수 단위 테스트: 태그 경계 우선, 긴 단어 글자 단위)
2. ASCII가 아닌 글자가 들어간 태그에서도 오류 없이 시트가 만들어지고 `see sheet.html` 표시가 붙음
3. `sheet.html`이 만들어지고, 칸 수·그림 경로·라벨이 시트 기록과 일치. `<script src`, `<link`, `http`로 시작하는 외부 참조가 없음
4. 라벨에 `<b>&"'` 같은 글자가 있어도 HTML에 이스케이프되어 들어감
5. 0002의 여러 모델·시드 시트에서도 라벨·HTML이 칸 단위로 맞게 나옴
6. `nai_preset list`에서 80자 넘는 프롬프트가 잘리지 않음
7. 번들(`dist/index.js`, 0.2.1 기준 약 1,006KB) 증가가 100KB 이하. 자동 검사는 없으니 PR 설명에 전후 크기를 적기
8. 기존 테스트 전부 통과. 단 이 스펙 때문에 바뀌는 게 당연한 테스트는 새 동작에 맞게 고침 — `test/style.test.ts`의 시트 폴더 파일 목록 비교(`sheet.html` 추가)와 시트 높이 비교(라벨 영역 추가). 고친 테스트는 PR에 적기
